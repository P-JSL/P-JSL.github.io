기능 소개

ZIP을 설치 폴더에 압축 해제하여 확장 프로그램으로 로드할 수 있습니다.

01 / LOCAL

브라우저 로컬 실행

사용자 계정과 구독 없이 동작하도록 제공되는 개인용 확장입니다.

02 / MEDIA

미디어 감지와 저장

웹페이지의 미디어를 감지하고 다운로드합니다. 실제 지원 여부는 웹사이트에 따라 다릅니다.

03 / INTEGRITY

무결성 확인

확장 버전, SHA-256과 파일 크기를 제공하여 파일을 검증할 수 있습니다.

설치 방법

Chrome 120 이상을 기준으로 작성했습니다.

1

ZIP 다운로드

ZIP 파일을 내려받아 압축을 해제합니다.

2

확장 관리 열기

Chrome 주소창에 chrome://extensions를 입력합니다.

3

개발자 모드 활성화

개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 클릭합니다.

4

폴더 선택

manifest.json이 있는 my-video-app 폴더를 선택합니다. 업데이트 후 확장 프로그램을 새로고침합니다.

YouTube 다운로드는 별도의 도우미 ZIP과 Python·Deno 설정이 필요한 기능이 있습니다. 이 확장 ZIP에 도우미는 포함되어 있지 않습니다.
