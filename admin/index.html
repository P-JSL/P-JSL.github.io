프로그램 ZIP 파일 관리

권한이 있는 GitHub 계정으로 인증하고 파일을 P-JSL/P-JSL.github.io/downloads/에 직접 업로드합니다.

1. 관리자 인증

GitHub에서 P-JSL.github.io 저장소만 선택하고 Contents: Read and write 권한을 지정한 짧은 유효기간의 토큰을 입력하세요. 인증 확인 후 입력 필드는 비웁니다. 토큰은 서버·브라우저 저장소에 저장하지 않고 GitHub API 호출에만 사용합니다.

GitHub에서 토큰 관리

2. ZIP 파일 업로드

이 화면은 25MiB 이하 ZIP을 지원합니다. extension 등 특정 파일명은 필요하지 않습니다. ZIP 내부의 manifest.json 또는 Windows 실행 파일(.exe)로 종류를 구분하고, 각 유형의 최신 파일을 독립적으로 게시합니다.

GitHub Actions 배포 확인 · 확장 ZIP · 일반 다운로드 페이지

250MB ZIP 업로드

250MB 파일은 이 화면에서 Git 저장소에 직접 업로드할 수 없습니다. GitHub는 단일 Git 객체 크기를 100MiB로 제한합니다.

현재 제공하신 Windows 데스크톱 ZIP은 약 247.5MB입니다. 공개 저장소 P-JSL/P-JSL.github.io의 Releases → Draft a new release에서 새 버전 태그를 선택하고 ZIP을 첨부한 후 게시하세요. 일반 홈페이지가 공개 Release의 최신 Windows ZIP을 자동으로 찾아 다운로드 버튼에 연결합니다.

250MB를 이 관리자 화면 안에서 직접 업로드하려면 별도 인증·스트리밍 업로드 API와 외부 바이너리 저장소가 추가로 필요합니다. 비공개 P-JSL/myapps의 Release 링크는 일반 방문자가 받을 수 없으므로 반드시 공개 저장소에 게시하세요.
