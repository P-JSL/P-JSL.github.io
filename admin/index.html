확장 프로그램 파일 관리

권한이 있는 GitHub 계정으로 인증하고 파일을 P-JSL/P-JSL.github.io/downloads/에 직접 업로드합니다.

1. 관리자 인증

GitHub에서 P-JSL.github.io 저장소만 선택하고 Contents: Read and write 권한을 지정한 짧은 유효기간의 토큰을 입력하세요. 인증 확인 후 입력 필드는 비웁니다. 토큰은 서버·브라우저 저장소에 저장하지 않고 GitHub API 호출에만 사용합니다.

GitHub에서 토큰 관리

2. ZIP 파일 업로드

이 화면의 직접 Git 업로드는 안정성을 위해 25MiB 이하로 제한합니다. 파일명에 extension을 포함하세요. 같은 파일명은 기존 파일을 업데이트하며, GitHub Actions가 가장 최근 커밋된 확장 ZIP을 다운로드 파일로 선택합니다.

GitHub Actions 배포 확인 · 현재 다운로드 파일

250MB ZIP 업로드

250MB 파일은 이 화면에서 Git 저장소에 직접 업로드할 수 없습니다. GitHub는 단일 Git 객체 크기를 100MiB로 제한합니다.

250MB 배포 시 GitHub Releases(파일당 2GiB 미만) 또는 Cloudflare R2/S3와 같은 외부 파일 저장소가 필요합니다. 홈페이지에서 직접 250MB 파일을 업로드하려면 관리자 인증과 대용량 스트리밍을 처리하는 서버리스 API를 추가해야 합니다.

GitHub Pages 배포 자체는 1GB까지 지원하므로, 별도 저장소에서 Actions 빌드 중 250MB 파일을 가져와 _site/downloads/에 넣는 방식은 가능합니다. 이 별도의 릴리스 연동은 현재 관리자 직접 업로드와 구분됩니다.
