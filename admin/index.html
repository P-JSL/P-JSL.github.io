배포 파일 관리

25MiB 이하 ZIP을 GitHub의 downloads/ 폴더에 게시합니다. 파일 이름에 extension을 포함할 필요는 없습니다.

Windows 데스크톱 대용량 파일

25MiB보다 큰 ZIP은 이 업로드 기능에서 처리할 수 없습니다. 250MB Windows 파일은 공개 GitHub Release에 첨부하세요.

배포 흐름

메뉴·화면 변경 → site-pages.json 직접 커밋 → GitHub Actions → GitHub Pages 배포

데이터는 블록 JSON으로 저장됩니다. 임의 HTML·JavaScript 입력은 실행하지 않습니다. 기존 텍스트형 페이지는 그대로 표시되며, 편집 시 블록 구조로 변환됩니다.
